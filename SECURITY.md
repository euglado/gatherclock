# Security / Güvenlik

Do not post credentials or exploitable private details in public issues.
Use the repository's Security → Report a vulnerability option if available;
otherwise open an issue asking for a private reporting channel without the
exploit details. If your token leaks, reset it immediately in the Discord
Developer Portal and rerun setup. Deleting a commit does not revoke a token.

Public issue'lara kimlik bilgisi veya istismar ayrıntısı koymayın. Varsa deponun
Security → Report a vulnerability seçeneğini kullanın; yoksa ayrıntı vermeden
özel bildirim kanalı isteyin. Token sızarsa Developer Portal'da hemen sıfırlayın
ve kurulumu tekrarlayın. Commit silmek tokenı geçersiz kılmaz.

This project has no hosted reporting service or guaranteed response time.
Bu projenin barındırılan bildirim servisi veya garanti yanıt süresi yoktur.
